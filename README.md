This repository presents my **Gmsh meshing work**, developed through practical experiments and **official Gmsh tutorials (T1–T21)**.  
The focus is on **geometry creation, mesh generation, and mesh control techniques**, demonstrated using **structured and unstructured meshes** for components such as an **impeller sector**.

## Key Topics
- Gmsh `.geo` scripting  
- Automatic and transfinite meshing  
- Mesh grading and refinement  
- Background mesh fields  
- Physical groups for CFD/FEA  

## Applications
- CFD preprocessing  
- Structural analysis meshing  
- Turbomachinery (impeller meshes)  

## Tools Used
- Gmsh (GUI & scripting)
